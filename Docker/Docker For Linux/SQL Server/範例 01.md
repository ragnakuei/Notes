# mcr.microsoft.com/mssql/server

## tag 2022-latest

```bash
sudo docker pull mcr.microsoft.com/mssql/server:2022-latest

sudo docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=YourStrong@Passw0rd" -p 1433:1433 --name sql1 --hostname sql1    -d    mcr.microsoft.com/mssql/server:2022-latest

docker exec -t sql1 cat /var/opt/mssql/log/errorlog | grep connection
```

進入 container 中的 bash

```bash
sudo docker exec -it sql1 "bash"
```

在 bash 中執行 sqlcmd

```bash
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrong@Passw0rd'
```

## tag 2019-latest

建立 Container 並 mount 本地端資料夾 volumn

win

```bash
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=q1w2E#R$" -e "MSSQL_PID=Developer" --name sqlserver2019_01 -p 8085:1433 -v C:/docker/CoreMvc/DB:/var/opt/mssql/data -d mcr.microsoft.com/mssql/server:2019-latest
```

osx

```bash
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=q1w2E#R$" -e "MSSQL_PID=Developer" --name sqlserver2019 -p 8089:1433 -v /Volumes/K_480G/Docker/DB/sqlserver2019:/var/opt/mssql/data -d mcr.microsoft.com/mssql/server:2019-latest
```

可以在 SSMS 以這樣的伺服器名稱來連線至該 DB

```
.,8085
.\,8085
```

進入 Container 的方式

```bash
docker exec -it sqlserver2019_01 bash
docker exec -it sqlserver2019_01 /opt/mssql-tools/bin/sqlcmd -S localhost -U sa -P q1w2E#R$
```

進入 sqlcmd 後，可透過以下的方式來 attach DB

```sql
CREATE DATABASE [CoreMvc] ON (FILENAME = '/var/opt/mssql/data/CoreMvc.mdf')
LOG ON (FILENAME = '/var/opt/mssql/data/CoreMvc_log.ldf')
FOR ATTACH;
GO
```
