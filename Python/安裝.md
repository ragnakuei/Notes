# 安裝

## mac

### pyenv

類似 node.js 的 nvm 套件，用來管理本機執行的 python 版本 !

目前最建議的做法

安裝

```shell
brew install pyenv
```

執行以下指令，將 pyenv 的環境變數套用在 zsh 中 !

```shell
echo '' » ~/.zshrc
echo '# fix pyenv python path' >> ~/.zshrc
echo 'eval "$(pyenv init --path)"' >> ~/.zshrc
```

重新開啟 terminal，再參考以下指令：

```shell
pyenv install 3.12.3
pyenv versions
pyenv shell 3.12.3
pyenv global 3.12.3
pyenv local 3.12.3
```

後續就用 python 指令執行即可 !

shell / local / global 的差異

-   shell：只在目前 shell 中有效
-   local：只在目前目錄中及子目錄有效
-   global：全域有效

### 透過 homebrew 安裝

```shell
brew install python
```

後續就用 python3 指令執行即可 !

透過官方安裝檔進行安裝

-   https://www.python.org/downloads/

驗証安裝

```shell
python3 --version
python3 -V
```

-   注意大小寫
