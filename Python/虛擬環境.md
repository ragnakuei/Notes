# 虛擬環境

主要用意是為了讓各 python 專案所執行的 python 版本、套件，能夠互相獨立而互不影響 !

## virtualenv

參考資料
- [python.org](https://docs.python.org/zh-tw/3/library/venv.html)


### 手動建立虛擬環境 (win)

```bash
python -m venv [project_path]
cd [project_path]
.\Scripts\activate.bat
```

可以透過

```cmd
where python
```

來查看 python 的路徑，如果是在該專案路徑中，就可以了 !

### 透過 poetry 建立專案後，預設就會套用了 !

停用當前目錄所使用的 virtualenv 環境

```bash
deativate
```

啟用當前目錄所使用的 virtualenv 環境

```bash
source .venv/bin/activate
```
