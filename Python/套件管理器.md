# 套件管理器

## poetry

poetry

安裝

```bash
curl -sSL https://install.python-poetry.org | python3 -
poetry --version
poetry config --list
```

設定在 project 中使用 virtualenv

```bash
poetry config virtualenvs.in-project true
```

建立專案

```bash
poetry new project01
cd project01
```

安裝專案內所有套件

```bash
poetry install
```

確認是否使用專案內 venv 的 python 套件

```bash
which python
```

如果沒有的話，輸入下面的指令後，再進行確認

```bash
poetry lock
```

取得目前專案內所使用的 python 版本

```bash
poetry run python --version
```

指定目前專案內所使用的版本

```bash
poetry env use [python version]
```

注意，這還是要先讓本機可執行的 python 可以支援該版本後，才可以順利切換過去 !

例，要依照下面的順序，才可以讓 poetry 指定該 python 成功 !

```bash
pyenv local 3.8.19
poetry env use 3.8.19
```

解除安裝

```bash
curl -sSL https://install.python-poetry.org | python3 - --uninstall
```
