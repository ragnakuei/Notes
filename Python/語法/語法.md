# 語法

## 特性

-   動態型別
    -   不代表是弱型別
-   不用事先宣告變數
-   大小寫視為相異
-   不需要 ; 結尾
-   用縮排來區分 block
-   四則運算
    -   字串 \* n 就會是字串 repeat n 組成的長字串

## 資料型態

型別檢查方式

-   type(a) == type
-   isinstace(a, type)

```python
from typing import Optional, Union

def test(a : Optional[Union[str, int]] = None):
    if a is None:
        print("a is None")
        return

    # if isinstance(a, str):
    if(type(a) == str):
        print("a is str", a)
        return

    # if isinstance(a, int):
    if(type(a) == int):
        print("a is int", a)
        return

    print("a is not None", a)

test()
test(None)
test(1)
test('s')
```

    ```python
    class Prev:
        def __init__(self, text):
            self.text = text

        #     # 會把 | 後方的物件當作參數，傳入此物件的 other 參數
        def __or__(self, input):
            return input.Run(self.text)


    class Next:
        def Run(self, input):
            return f"Run: {input}"

    print(Prev("What is the weather like today?") | Next())
    ```
