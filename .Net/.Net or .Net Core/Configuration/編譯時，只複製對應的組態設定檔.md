# 編譯時，只複製對應的組態設定檔

假設組態有三個 Local / Test / Release

### Program.cs 設定方式

```cs
builder.Configuration
       .AddJsonFile("appsettings.json",
                    optional: false,
                    reloadOnChange: true)
        #if LOCAL
       .AddJsonFile("appsettings.Local.json",
                    optional: false,
                    reloadOnChange: true)
        #endif
        #if TEST
       .AddJsonFile("appsettings.Test.json",
                    optional: false,
                    reloadOnChange: true)
        #endif
        ;
var config = builder.Configuration;

// ...

builder.Services.Configure<AppSettingDto>(config);
```

### .csproj 設定方式

概念

-   先移除 appsettings.\*.json 的複製動作
-   再加上對指定組態的複製動作

做法：

以下不同做法的效果相同

1.  
    ```xml
    <ItemGroup>
        <Content Remove="appsettings.*.json"/>
        <None Include="appsettings.$(Configuration).json" CopyToOutputDirectory="Always" CopyToPublishDirectory="Always"/>
    </ItemGroup>
    ```

1.  
    ```xml
    <ItemGroup>
        <Content Remove="appsettings.*.json"/>
        <Content Include="appsettings.Local.json" Condition="'$(Configuration)'=='Local'" CopyToOutputDirectory="PreserveNewest" CopyToPublishDirectory="PreserveNewest" />
        <Content Include="appsettings.Test.json" Condition="'$(Configuration)'=='Test'" CopyToOutputDirectory="PreserveNewest" CopyToPublishDirectory="PreserveNewest" />
    </ItemGroup>
    ```
