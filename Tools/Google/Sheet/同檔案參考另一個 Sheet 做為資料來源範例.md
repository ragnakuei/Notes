# 同檔案參考另一個 Sheet 做為資料來源範例

```
=ARRAYFORMULA(
  QUERY(
    {
      '複訓'!B2:B51,            
      '複訓'!D2:D51, 
      IF('複訓'!AI2:AI51="通過","1",""), 
      '複訓'!AI2:AI51           
    },
    "SELECT Col1, Col2, Col3 WHERE Col4 = '通過'",
    0
  )
)
```

QUERY 給的參數
- 第一個
    - 資料來源，{ } 中的每個欄位為相同數量的欄位，這邊的欄位為相同 Sheet 的不同欄位

- 第二個
    - 查詢條件，使用 SQL 語法，這邊是選擇 Col1, Col2, Col3 並且過濾 Col4 為 '通過' 的資料
    - Col1 對應的是第一個參數的 '複訓'!B2:B51
    - Col2 對應的是第一個參數的 '複訓'!D2:D51
    - Col3 對應的是第一個參數的 IF('複訓'!AI2:AI51="通過","1","")
    - Col4 對應的是第一個參數的 '複訓'!AI2:AI51

- 第三個
    - 標題列數量，這邊是 0 表示沒有標題列
