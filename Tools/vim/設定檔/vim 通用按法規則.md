### Normal Mode

Basic

-   <Esc> 清除搜高亮結果

Editor

-   <Leader>a 全選
-   <Tab> 增加縮排
-   <S-Tab> 減少縮排
-   <C-h> 游標 ←
-   <C-j> 游標 ↓
-   <C-k> 游標 ↑
-   <C-l> 游標 →
-   <A-S-j> 整行往下移
-   <A-S-kl> 整行往上移
-   <C-S-j> 所在的 statement / block 往下移
-   <C-S-k> 所在的 statement / block 往上移
-   <Leader>; 補上字尾的 ;
-   <Leader>, 補上字尾的 ,

Navigation

-   <A-h> Back
-   <A-l> Forward
-   <A-u> 顯示游標所在成員呼叫點至新視窗中，原 <A-Home>
-   <A-m> 顯示游標所在成員呼叫點至彈出視窗中，原 <A-End>
-   <A-j> 移至實作
-   <A-k> 移至父層宣告
-   <A-i> 移至上方最接近的 Method，原 <A-PageUp>
-   <A-,> 移至下方最接近的 Method，原 <A-PageDown>
-   <Home> 移至同一行最前方
-   <End> 移至同一行最後方
-   <A-]> 移至所在 { } block 的 }
-   <A-[> 移至所在 { } block 的 {
-   <A-0> 移至所在 ( ) block 的 )
-   <A-9> 移至所在 ( ) block 的 (
-   <Leader>f <PageDown>
-   <leader>b <PageUp>
-   <Leader>ne 移至同檔案內下一個錯誤

Tab

-   <Leader>tw 關閉目前分頁
-   <Leader>tcb 關閉目前分頁往下/右的所有分頁 below
-   <Leader>tca 關閉目前分頁往上/左的所有分頁 above
-   <Leader>tu Toggle Pin 目前的分頁
-   <Leader>tp Pin 目前的分頁

Operator

-   <Leader>cf 建立檔案
-   <A-S-l> 移至檔案列表中的目前檔案
-   <A-S-o> 移至檔案總管中的目前檔案
-   <A-S-f> 格式化文件

AceJump

-   <Leader>jw

Refactor

-   <Leader>il inline
-   <Leader>iv introduce variable
-   <Leader>if introduce field
-   <Leader>ip introduce parameter
-   <Leader>em extract method
-   <Leader>sw surround with

VCS

Github Copilot

<Leader>cm 開啟 copilot popup menu
<Leader>ca 開啟 Copilot Chat
