# 物件巢狀結構

用 FOR JSON PATH 來物件巢狀結構

當需要將查詢結果輸出成巢狀結構的 JSON 時，需要再加上 JSON_QUERY() 來將查詢結果轉換成 JSON 物件。

就不會看到 \\" 這樣的字串了。

```sql
DECLARE @sourceData nvarchar(max) = (
                                        SELECT 'a' AS [A],
                                               'b' AS [B],
                                               'c' AS [C]
                                        FOR JSON PATH, WITHOUT_ARRAY_WRAPPER
                                    )

DECLARE @logContent nvarchar(max) = (
                                        SELECT 'a'                     AS [ErrorMessage],
                                               'b'                     AS [ErrorSeverity],
                                               'c'                     AS [ErrorState],
                                               JSON_QUERY(@sourceData) AS [MailInfo]
                                        FOR JSON PATH, WITHOUT_ARRAY_WRAPPER
                                    )
SELECT @logContent
```

輸出結果

```
{"ErrorMessage":"a","ErrorSeverity":"b","ErrorState":"c","MailInfo":{"A":"a","B":"b","C":"c"}}
```
