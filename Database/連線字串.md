# 連線字串

範例：

```
// 資料庫帳密
Server=myServerAddress;Database=myDataBase;User ID=myUser;Password=myPassword;Trusted_Connection=True;TrustServerCertificate=True;
```

```
// 目前登入帳號
Server=myServerAddress;Database=myDataBase;Integrated Security=True;Trusted_Connection=True;TrustServerCertificate=True;
```

TrustServerCertificate=True;
> 直接信任 SQL Server 憑證
